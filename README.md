Netflix Data Analysis using Power BI

Project Overview

This project analyzes Netflix movies and TV shows using Microsoft Power BI. It presents data through visualizations to help understand Netflix content and trends.

Objectives

- Analyze Netflix movies and TV shows.
- Compare the distribution of movies and TV shows.
- Explore content by country, genre, and release year.
- Create an interactive dashboard to present insights.

Tools Used

- Microsoft Power BI
- Power Query (if used)
- CSV Dataset

Dataset

The dataset used in this project is "netflix_titles.csv". It contains information about Netflix titles, including type, title, director, country, release year, rating, and genre where available.

Project Files

- "Netflix Dashboard.pbix" — Power BI dashboard file.
- "netflix_titles.csv" — Dataset used for analysis.

Key Insights

The dashboard presents the distribution of movies and TV shows and explores patterns in Netflix content. Refer to the dashboard for the actual results and findings.

How to View

1. Download "Netflix Dashboard.pbix".
2. Open it in Microsoft Power BI Desktop.
3. If required, reconnect the dataset and refresh the report.
